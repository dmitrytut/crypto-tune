# Sound v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this
> plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** LIVE tension без разогрева, реакция звука на скачки за ~1 с, база без повторов.

**Architecture:** История грузит адаптер Binance и выдаёт её до живых сделок (контракт
`MarketFeed`), метрики и `main.ts` не меняются. Всё звуковое: чистые функции в
`arp-pattern.ts`/`tension-map.ts` (specs), Tone-граф в слоях; новый `AmbienceLayer` в канале базы.

**Tech Stack:** TypeScript 7, Tone.js 15, vitest, Biome.

**Spec:** `docs/superpowers/specs/2026-10-23-sound-v2-design.md`

## Global Constraints

- Слои берут транспорт у своего узла (`this.loop.context.transport`), не `Tone.getTransport()`.
- Каждое изменение параметра звука — через `rampTo`/запланированные рампы.
- `transport.bpm` не автоматизировать `rampTo` на каждом тике.
- Specs в `src/<module>/__specs__/<file>.spec.ts`; экспорт только для specs/соседей — `/** @package */`.
- Константы реализации — `UPPER_SNAKE` вверху файла, с единицами.
- Перед коммитом: `pnpm check && pnpm test && pnpm build`.

### Task 2: Отзывчивость — чистая часть

**Files:** Modify `src/audio/arp-pattern.ts`, `src/audio/tension-map.ts`, specs рядом;
`src/settings.ts`, `src/metrics/engine.ts` (N = 5).

**Interfaces:**
- `entryStep(contour: Contour, fromDegree: number): number` — шаг фразы `contour`, с которого
  продолжать после ступени `fromDegree` (ступень ближайшая к `fromDegree`, следующий за ней шаг).
- `stepShock(prev: ShockState, tension: number, ts: number): { state: ShockState; fired: boolean }`,
  `INITIAL_SHOCK: ShockState`.
- `TensionMix` без изменений полей.

- [ ] Specs `entryStep`: из ступени 5 спокойного контура в `up` → следующая нота 6; в `down` → 4.
- [ ] Specs `stepShock`: скачок 0.2 → 2.5 за 3 тика — `fired`; плавный рост 0.1/тик до 3 — нет;
  второй скачок внутри кулдауна — нет, после кулдауна — да; ниже `mid` — нет.
- [ ] Specs `tensionMix`: при tension 1.5 саб ≥ 0.5, шейкер > 0.1; на 1 оба 0; монотонность.
- [ ] Реализация, N = 5 в `DEFAULT_SETTINGS` и `DEFAULT_METRICS_CONFIG`. Тесты зелёные. Commit.

### Task 3: Отзывчивость — звук

**Files:** Modify `src/audio/base-layer.ts`, `src/audio/tension-layer.ts`, `src/audio/engine.ts`.
- [ ] `BaseLayer`: контур применяется на следующей ноте через `entryStep`; удвоение на
  `transport.nextSubdivision('4n')`; пропуски слабых долей с вероятностью
  `MAX_REST_PROB * (1 − intensity)`.
- [ ] `TensionLayer.shock(up: boolean, time: number)`: pink noise → bandpass → gain; рампа
  0 → `SHOCK_GAIN` за 0.6 с → 0 за 1.4 с; частота 300 → 4000 Гц (вверх) или 4000 → 300 (вниз).
- [ ] `AudioEngine.update`: `stepShock(state, s.tension, s.ts)`; при `fired` —
  `g.tension.shock(s.ret >= 0, Tone.now())`.
- [ ] Офлайн-рендер: волна слышна (RMS +), без клиппинга. Commit.

### Task 5: Петли Ино + пульс (`AmbienceLayer`)

**Files:** Create `src/audio/ambience-layer.ts`; Modify `src/audio/engine.ts`.
- [ ] `AmbienceLayer(output, tonicPc)`: `start(time)`, `stop(time)`, `setTonic(pc)`.

- [ ] Подключение в канал базы в `AudioEngine.build/start/stop/setParams`.
- [ ] Офлайн-рендер: колокольчики и пульс слышны, RMS базы растёт не более чем на 3 дБ. Commit.
