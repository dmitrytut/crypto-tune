## Упрощения и устранение дублирования

- Общая формула предела старых REST-страниц используется для paging и оценки пригодности кэша.
- `stage.ts`: один расчёт размещения вместо раздельной логики origin/chart и двух observers.
- `aura.ts`: одна подготовка GPU-ресурсов для создания и восстановления контекста.
- Picker очищает выделение через существующий `highlight(-1)`, без второго способа сброса.
- Share использует один путь запуска readiness-таймера.
- Аудиограф останавливает собственный transport; master подключается к destination своего
  контекста. Live и offline не зависят здесь от глобального Tone-контекста.
- Удалены неиспользуемые `RollingStats.clear()`, аргумент `shift` у `arpDegree`, выходное поле
  `TensionMix.peak`, лишний HTML id и недостижимое CSS-правило пустого статуса клипа.
  Производственные callers и спецификации обновлены, совместимые заглушки не оставлены.
- README исправлен: interaction sounds по фактической настройке включены по умолчанию.
- Новых библиотек, общих `utils`/`types`-слоёв и перестановки каталогов ради внешнего порядка нет.

## Идеи улучшений — отдельно от обязательных исправлений

1. **Проверки до merge.** Сейчас deployment workflow выполняет check/test/build при push
   в `master`; добавить отдельную проверку `pull_request`, оставив публикацию только master.
   Это практичнее изменения архитектуры приложения. CI в рамках ревью не перенастраивался.
2. **Профилирование длительного сеанса на телефоне.** Измерить GC от `ClipBuffer.filter`,
   накопление маркеров графика, стоимость collision loop на верхнем лимите частиц и
   растущий BPM timeline при непрерывном воспроизведении. Без профиля не заменять массивы
   ring buffer-ами и не вмешиваться во внутренние коллекции Tone.
3. **Шаринг произвольной пары.** Сейчас пары вне набора landing pages и COIN-M ведут на
   главную — это явно заданное и покрытое спецификацией поведение, не случайный дефект.
   Если продукту нужен точный deep link, использовать уже поддерживаемые `pair`/`market`
   query-параметры и изменить соответствующий контракт, а не добавлять второй роутер.
4. **Аппаратная матрица.** Проверить iOS interrupted AudioContext, восстановление WebGL,
   software fallback и экспорт клипа на реальных мобильных устройствах. Переход на `highp`
   исключён из этого PR: остаётся `mediump`; менять точность следует отдельно, с замерами GPU.
5. **Регулярный браузерный smoke.** Зафиксировать небольшую проверку picker/dialog,
   Listen/Stop и одного клипа, если проект готов поддерживать browser-инфраструктуру.
   Не дублировать чистые unit-тесты набором DOM wiring-проверок.

## Осознанные ограничения

- Короткий кэш теперь может вызвать повторную REST-волну: до 20 запросов, вес 400 при
  лимите Binance 2400/мин. Быстрый reload редкой пары тоже иногда повторяет несколько страниц.
  Принято ради восстановления истории; busy-cache, достигающий предела волны, переиспользуется.
- Первоначальная синхронизация визуальных часов зависит от задержки первого сообщения.
  Если страница блокируется ещё до него, абсолютный skew и сетевую задержку нельзя разделить
  по одному sample. После калибровки очередь не сдвигает визуальное время назад.
  Фиксированная поправка предполагает, что системные часы не меняют вручную во время сеанса;
  после такого изменения нужна перезагрузка или новый pipeline.
- Существующие документированные ограничения REST (pace shortcut, лимит страниц,
  sub-second lag), отсутствие автоматического retry COIN-M contract specs, синхронная часть
  offline graph build и редкий неуспех reverb generation не переписывались без новой
  воспроизводимой проблемы и оправданного эффекта.
- Потеря контекста посреди offline-рендера всё ещё может дать пустые кадры ауры; восстановление
  обычной сцены не является обещанием восстановления произвольного аварийного экспорта.
